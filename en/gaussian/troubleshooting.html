How to find the error

Look at the end of the output file. The cause is printed a few lines above Error termination. If there is no termination line at all, the job is still running or was killed by a time, memory or disk limit.

Input format errors (the job stops before calculating)

If the output is short and ends with Error termination in l1.exe (route-line errors), l101.exe or l301.exe, the input file is almost certainly the problem. Check in order:

  1. Blank lines: one after the route line, one after the title, one after the coordinates.
  2. Spelling on the route line (Opt Freq, B3LYP, 6-31G(d)).
  3. Exactly one charge/multiplicity line, and a possible combination (odd electron count with multiplicity 1 is an error).
  4. Coordinates in four columns (symbol x y z), with no tabs or full-width characters.
  5. A blank line after any extra input such as ModRedundant or a basis-set block.
