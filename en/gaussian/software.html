Quantum chemistry programs

Software What it does Interface Cost Links
Gaussian A long-established, widely used quantum chemistry program: Opt, Freq, NMR, TD, TS, IRC and more. Command line / job scheduler Commercial Official
ORCA Covers much the same range of calculations as Gaussian. Command line Free for academic use Official · Manual · Neese, WIREs Comput. Mol. Sci. 2025
Q-Chem DFT, wavefunction methods, excited states, NMR. Command line Commercial (trial available) Official · Epifanovsky et al., J. Chem. Phys. 2021
TURBOMOLE DFT, MP2, NMR, excited states, optical rotation. The engine behind CENSO's optical-rotation workflow. Command line / GUI Commercial (educational license) Official · Franzke et al., J. Chem. Theory Comput. 2023
CREST / xTB Fast conformer searches with the semiempirical GFN-xTB methods. Command line Free, open source CREST · xTB · Pracht et al., J. Chem. Phys. 2024

Building and viewing structures

Software What it does Interface Cost Links
ChemDraw Draws 2D structures. Set stereochemistry with wedge/hash bonds and save as .mol/.mol2 or similar for a 3D builder. GUI Commercial (your institution may have a license) Official
ReShiki Draws 2D structures; exchanges structures with ChemDraw by copy and paste and saves .mol files. GUI Free, open source Official · GitHub
Spartan Integrated environment to build molecules, search conformers with MMFF and run DFT. GUI Commercial Official
CONFLEX Exhaustive conformer searches with force fields. GUI / command line Commercial Official
Avogadro Builds and displays molecules, optimizes structures with force fields, and prepares inputs for quantum chemistry programs. GUI Free, open source Official · Hanwell et al., J. Cheminform. 2012
Open Babel Converts between more than 110 structure file formats; can also generate 3D coordinates from 2D structures. GUI / command line Free, open source Official · O'Boyle et al., J. Cheminform. 2011
GaussView The official Gaussian GUI; builds inputs and displays structures, vibrations and IRCs. GUI Commercial Official
Facio Builds molecules, prepares inputs for Gaussian and other programs, and displays results. GUI Free Official
Chemcraft Displays structures, vibrations and optimization progress from Gaussian output. GUI Commercial (trial) Official
CYLview Reads Gaussian outputs (.log/.out) and XYZ files to make publication-quality 3D structure figures; also shows optimization steps and vibrations. GUI Free Official · Manual
Mercury CCDC's structure viewer. It displays .xyz files with several structures and is recommended by JOC for checking coordinate files before submission. GUI Free version (non-commercial use) Official
SEQCROW ChimeraX extension for viewing/editing quantum-chemistry output and building inputs. GUI (ChimeraX plugin) Free Official · Schaefer et al., J. Comput. Chem. 2021

Conformer screening, thermochemistry and automation

Software What it does Interface Cost Links
CENSO Refines conformer ensembles (such as CREST output) with DFT in stages and can automate NMR, optical rotation and UV calculations (requires a separate quantum chemistry program such as ORCA). Command line / Python Free Official
GoodVibes Computes thermal corrections, populations and combinations with high-level SPs from Freq outputs in one go. Command line / Python Free Official · Luchini et al., F1000Research 2020
Shermo Computes thermochemistry and low-frequency corrections from Freq outputs. Command line Free Official · Lu & Chen, Comput. Theor. Chem. 2021
AQME Automates input preparation (QPREP) and checking/fixing of results (QCORR) for many conformers. Command line / Python Free Official · Alegre-Requena et al., WIREs Comput. Mol. Sci. 2023
ACCeL A Python library for conformer selection, populations and batch input generation. Python Free Official
cclib Python library that parses coordinates, energies and frequencies from Gaussian, ORCA and other outputs into one format. Python Free Official
AaronTools Python toolkit for molecule editing, input generation, output parsing and thermochemistry; the basis of SEQCROW. Python Free Official
ExcelAutomat Excel macros for batch extraction of outputs, input preparation and tabulation. Excel Free (registration) Official · Laloo et al., J. Comput. Aided Mol. Des. 2017

Spectra and structure determination

Software What it does Interface Cost Links
SpecDis Builds ECD/UV curves from TD outputs, averages them over conformers and overlays experiment. GUI Free for non-commercial use Official · Bruhn et al., Chirality 2013
SpectroIBIS Checks duplicate conformers and imaginary frequencies, averages NMR/ECD over conformers and builds SI tables. GUI (Windows) Free Official · Bulcock et al., J. Nat. Prod. 2025
DP4+ App Official implementation of DP4+, which assigns probabilities to candidate structures from calculated NMR shifts. Python (with GUI) Free Official · DP4+App, J. Nat. Prod. 2023 · Grimblat et al., J. Org. Chem. 2015
ML-J-DP4 Evaluates configuration from experimental ³JH,H and machine-learning-corrected shieldings. Python Free Official · Tsai et al., Org. Lett. 2022
CHESHIRE A website collecting scaling factors for computed NMR chemical shifts and J couplings, by level of theory. Web Free Official · Lodewyk et al., Chem. Rev. 2012
Multiwfn Wavefunction analysis, including ECD/UV curves, NBO-like analysis and electron-density visualization. Interactive command line Free Official · Lu & Chen, J. Comput. Chem. 2012
