Quantum chemistry programs

Software What it does Interface Cost Links
Gaussian
Gaussian, Inc.		 Opt, Freq, NMR, TD, TS, IRC and more. Command line / job scheduler Commercial —
ORCA
group of Prof. Frank Neese; FACCTs		 DFT and wavefunction methods, NMR, excited states, TS and IRC. Command line Free for academic use Manual · Neese, WIREs Comput. Mol. Sci. 2025
Q-Chem
Q-Chem, Inc.		 DFT, wavefunction methods, excited states, NMR. Command line Commercial (trial available) Epifanovsky et al., J. Chem. Phys. 2021
TURBOMOLE
TURBOMOLE GmbH		 DFT, MP2, NMR, excited states, optical rotation. Command line / GUI Commercial (educational license available) Franzke et al., J. Chem. Theory Comput. 2023
CREST / xTB
CREST: Philipp Pracht · xTB: Grimme group (Bonn)		 Fast conformer searches with the semiempirical GFN-xTB methods. Command line Free, open source Pracht et al., J. Chem. Phys. 2024

Building and viewing structures

Software What it does Interface Cost Links
ChemDraw
Revvity Signals Software, Inc.		 Draws 2D structures. Set stereochemistry with wedge/hash bonds and save as .mol, .mol2 or a similar format to open in a 3D builder. GUI Commercial (your institution may have a license) —
ReShiki
Ameyanagi		 Draws 2D structures; exchanges structures with ChemDraw by copy and paste and saves .mol files. GUI Free, open source GitHub
Spartan
Wavefunction, Inc.		 Integrated environment to build molecules, search conformers with MMFF and run DFT. GUI Commercial —
CONFLEX
CONFLEX Corporation		 Exhaustive conformer searches with force fields. GUI / command line Commercial —
Avogadro
The OpenChemistry / Avogadro Teams		 Builds and displays molecules, optimizes structures with force fields, and prepares inputs for quantum chemistry programs. GUI Free, open source Hanwell et al., J. Cheminform. 2012
Open Babel
The Open Babel Team		 Converts between more than 110 structure file formats; can also generate 3D coordinates from 2D structures. GUI / command line Free, open source O'Boyle et al., J. Cheminform. 2011
GaussView
Semichem Inc.		 The official Gaussian GUI; builds inputs and displays structures, vibrations and IRCs. GUI Commercial —
Facio
Masahiko Suenaga		 Builds molecules, prepares inputs for Gaussian and other programs, and displays results. GUI Free —
Chemcraft
Grigoriy A. Andrienko		 Displays structures, vibrations and optimization progress from Gaussian output. GUI Commercial (trial available) —
CYLview
Claude Y. Legault		 Reads Gaussian outputs (.log/.out) and XYZ files to make publication-quality 3D structure figures; also shows optimization steps and vibrations. GUI Free Manual
Mercury
The Cambridge Crystallographic Data Centre		 CCDC's structure viewer; displays .xyz files containing several structures. GUI Free version available for non-commercial use —
SEQCROW
QChASM		 ChimeraX extension for viewing/editing quantum-chemistry output and building inputs. GUI (ChimeraX plugin) Free Schaefer et al., J. Comput. Chem. 2021

Conformer screening, thermochemistry and automation

Software What it does Interface Cost Links
CENSO
Grimme group (grimme-lab)		 Refines conformer ensembles (such as CREST output) with DFT in stages and can automate NMR, optical rotation and UV calculations (requires a separate quantum chemistry program such as ORCA). Command line / Python Free —
GoodVibes
Robert Paton		 Computes thermal corrections, populations and combinations with high-level SPs from Freq outputs in one go. Command line / Python Free Luchini et al., F1000Research 2020
Shermo
Tian Lu		 Computes thermochemistry and low-frequency corrections from Freq outputs. Command line Free Lu & Chen, Comput. Theor. Chem. 2021
AQME
Juan V. Alegre-Requena		 Automates input preparation (QPREP) and checking/fixing of results (QCORR) for many conformers. Command line / Python Free Alegre-Requena et al., WIREs Comput. Mol. Sci. 2023
ACCeL
Keisuke Fukaya		 A Python library for conformer selection, populations and batch input generation. Python Free —
cclib
cclib Development Team		 Python library that parses coordinates, energies and frequencies from Gaussian, ORCA and other outputs into one format. Python Free —
AaronTools
QChASM		 Python toolkit for molecule editing, input generation, output parsing and thermochemistry; the basis of SEQCROW. Python Free —
ExcelAutomat
Computational Chemistry Group, University of Mauritius		 Excel macros for batch extraction of outputs, input preparation and tabulation. Excel Free (registration required) Laloo et al., J. Comput. Aided Mol. Des. 2017

Spectra and structure determination

Software What it does Interface Cost Links
SpecDis
T. Bruhn		 Builds ECD/UV curves from TD outputs, averages them over conformers and overlays them on the experimental spectrum. GUI Free for non-commercial use Bruhn et al., Chirality 2013, 25, 243
SpectroIBIS
Brodie Bulcock		 Checks duplicate conformers and imaginary frequencies, averages NMR/ECD over conformers and builds SI tables. GUI (Windows) Free Bulcock et al., J. Nat. Prod. 2025
DP4+ App
RosarioCCLab		 Official implementation of DP4+, which assigns probabilities to candidate structures from calculated NMR shifts. Python (with GUI) Free DP4+App, J. Nat. Prod. 2023 · Grimblat et al., J. Org. Chem. 2015, 80, 12526
ML-J-DP4
Sarotti-Lab		 Evaluates the configuration from experimental ³JH,H and machine-learning-corrected shieldings. Python Free Tsai et al., Org. Lett. 2022
CHESHIRE
Dean J. Tantillo		 A website collecting calibration equations for NMR chemical shifts and scaling factors for J couplings, by level of theory. Web Free Lodewyk et al., Chem. Rev. 2012, 112, 1839
Multiwfn
Tian Lu		 Wavefunction analysis, including ECD/UV curves, bonding and charge analysis and electron-density visualization. Interactive command line Free Lu & Chen, J. Comput. Chem. 2012
