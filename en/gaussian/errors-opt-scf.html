Opt and SCF errors

Geometry optimization (Opt)

Opt step limit

Number of steps exceeded,  NStep= 100

Cause: The structure did not converge within the step limit (MaxCycles; set by molecular size if not given). The output ends with Error termination, but this does not mean the input is wrong: the optimization stopped before it converged.

What to do
  1. Use the last geometry in the output (the final Input/Standard orientation) as the coordinates of a new input and rerun with the same settings.
  2. If the energy was steadily decreasing, this usually suffices.
  3. If it was oscillating, see “Oscillating optimization” below.
  4. After convergence, always run Freq and confirm that it also prints Stationary point found and that there are no imaginary frequencies.

Oscillating optimization (energy keeps going up and down)

Cause: The steps are too large, the estimated Hessian is poor or there is a floppy torsion (a bond that twists with little change in energy), so the structure keeps moving back and forth. There is no error text; the job eventually ends with Number of steps exceeded.

What to do
  1. Look at the energy trace and structures in a viewer such as GaussView, and check whether the amplitude is shrinking or keeps oscillating with the same amplitude.
  2. If it is shrinking, continue from the last geometry as above.
  3. If it keeps oscillating, rerun from the last geometry with Opt=(CalcFC,MaxStep=5): start from an exact Hessian and take smaller steps (5 is an example; the default is 30).

Job stops when atoms become collinear

Linear angle in Tors.
FormBX had a problem.
Error in internal coordinate system.

Cause: During the optimization three atoms became nearly collinear, and Gaussian can no longer build the internal coordinates (angles and dihedrals) it optimizes in (the job stops in l103).

What to do: Rerun from the last geometry with the same settings. If it stops again, rerun with Opt=Cartesian (optimize in Cartesian coordinates), which often needs more steps.

Not converged in the Freq after Opt

         Item               Value     Threshold  Converged?
 Maximum Force            0.000038     0.000450     YES
 RMS     Force            0.000014     0.000300     YES
 Maximum Displacement     0.005385     0.001800     NO
 RMS     Displacement     0.002819     0.001200     NO

Cause: Freq repeats the convergence test with the exact computed Hessian, so it can disagree with Opt, which uses an estimated Hessian. If the Freq output does not say Stationary point found., the structure is not a stationary point even when the number of imaginary frequencies is right, and the frequencies and thermochemistry are not valid. Checking for zero imaginary frequencies in a viewer such as GaussView does not show this; search the Freq part of the output file as text.

What to do: Continue the optimization from the same .chk, reading the Hessian computed in the Freq (example below), with the functional and basis set of the original job. Check again for Stationary point found. in the new Freq.

%chk=myfile.chk
#p B3LYP/6-31G(d) Opt=ReadFC Freq Geom=AllCheck Guess=Read

If the .chk is no longer available, calculate from the coordinates of the last optimized geometry with Opt=CalcFC Freq (the exact Hessian is computed at the first step).

#p B3LYP/6-31G(d) Opt=CalcFC Freq

If Stationary point found still does not appear after the new calculation, the structure may lie in a flat region of the potential energy surface. The default integration grid in Gaussian 16 is UltraFine; if you use Fine, try Int=UltraFine (use the same grid in every calculation you compare). See Gaussian: FAQ.

SCF convergence failure

SCF does not converge

Convergence failure -- run terminated.

Cause: The iterative calculation of the electronic structure (SCF) at one geometry did not converge. It can happen in Opt, TS or IRC jobs.

What to do
  1. First check for the common causes: a wrong charge/multiplicity, atom clashes or abnormal bond lengths in the structure.
  2. If those are fine, add SCF=XQC to the route line and rerun (adds quadratically convergent steps when the usual method fails).
  3. If XQC also fails, read the initial guess from the .chk of a nearby converged structure with Guess=Read. For an open-shell singlet with an unrestricted method, also try Guess=Mix.

Example rerun input for SCF failure

%chk=opt_scf.chk
#p B3LYP/6-31G(d) SCRF=(SMD,Solvent=Methanol)
 SCF=(XQC,MaxCycle=512) Opt=(CalcFC,MaxCycles=100) Freq

MaxCycle=512 raises the SCF iteration limit (default 64); it changes nothing for an SCF that converges within 64 cycles.

For the rest of the input, see Anatomy of an input file; for what each keyword does, see the keyword reference. Match the functional, basis set and solvent of the original job.
