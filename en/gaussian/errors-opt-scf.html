Opt and SCF errors

What to do when an optimization stops or the SCF fails to converge.

Geometry optimization (Opt)

Opt step limit

Number of steps exceeded,  NStep= 100

Cause: The structure did not converge within the cycle limit (MaxCycles; set by molecular size if not given). The output ends with Error termination, but the input is not wrong; the job simply stopped part-way.

What to do
  1. Use the last geometry in the output (the final Input/Standard orientation) as the coordinates of a new input and rerun with the same settings.
  2. If the energy was steadily decreasing, this usually suffices.
  3. If it was oscillating, see "Oscillating optimization" below.
  4. After convergence, always confirm with Freq that there are no imaginary frequencies.

Oscillating optimization (energy keeps going up and down)

Cause: Steps are too large, the Hessian approximation is poor, or there is a soft torsion, so the structure keeps bouncing. There is no error text; the job eventually ends with Number of steps exceeded.

What to do
  1. Look at the energy trace and structures in a viewer such as GaussView: is the amplitude shrinking, or bouncing at constant size?
  2. If shrinking, continue from the last geometry as above.
  3. If it keeps bouncing, rerun from the last geometry with Opt=(CalcFC,MaxStep=5): start from an exact Hessian and take smaller steps.

SCF convergence failure

SCF does not converge

Convergence failure -- run terminated.

Cause: The iterative electronic-structure calculation (SCF) at one geometry did not converge. It can happen in Opt, TS or IRC jobs.

What to do
  1. Check charge/multiplicity and look for atom clashes or abnormal bond lengths in the structure. This is the most common cause.
  2. If those are fine, add SCF=XQC to the route line and rerun (adds quadratically convergent steps when the usual method fails).
  3. If XQC also fails, read the initial guess from the .chk of a nearby converged structure with Guess=Read, or reconsider the method. For an open-shell singlet with an unrestricted method, also try Guess=Mix.

Example rerun input for SCF failure

%chk=opt_scf.chk
#p B3LYP/6-31G(d) SCRF=(SMD,Solvent=Methanol)
 SCF=(XQC,MaxCycle=512) Opt=(CalcFC,MaxCycles=100) Freq

Below the route line, continue with a blank line, title, blank line, charge/multiplicity, coordinates and a final blank line (input anatomy). Keyword meanings are in the keyword reference. Match the functional, basis set and solvent of the original job.
