Syntax rules

  • Link 0 lines start with % and come before the route line. The route line starts with # and may be wrapped over several lines, with no blank line in between.
  • Keywords are case-insensitive: Opt, opt and OPT are the same.
  • One option: Opt=Tight. Two or more: wrap in parentheses, Opt=(TS,CalcFC).
  • Functional and basis set are joined with a slash: B3LYP/6-31G(d).

The complete list is in the official Gaussian keyword reference.

Link 0 (% lines)

Keyword What it does and when to use it
%chk
%chk=catechin_opt.chk		 Checkpoint file for this job, used later to reread geometries or wavefunctions. Give each job its own name.
%oldchk
%oldchk=ts_freq.chk		 Reads the checkpoint of a previous job, e.g. to reuse a TS Hessian for an IRC.
%nprocshared
%nprocshared=8		 Number of cores. Match the allocation on the machine you run on.
%mem
%mem=16GB		 Amount of memory. Exceeding the machine's limit will stop the job.
%rwf Location of the read-write scratch file; pointing it at fast disk can speed up a job.

Job types

Keyword What it does and when to use it
SP Computes the energy at the given geometry (the default). Used to refine energies with a large basis set.
Opt Geometry optimization: finds a structure where the forces are nearly zero.
Freq Frequency analysis: tells a minimum from a TS by the number of imaginary frequencies at the optimized structure, and provides thermochemistry.
Opt Freq Runs Freq at the optimized geometry immediately after Opt.
IRC Follows the reaction path downhill from a TS toward reactant and product.
NMR Computes nuclear shieldings; GIAO by default. Spin–spin couplings are computed only with options such as NMR=SpinSpin.
TD
TD=(Singlets,NStates=50)		 Time-dependent DFT: excited states, used for UV and ECD.
Polar
Polar=OptRot CPHF=RdFreq		 Polarizability; Polar=OptRot gives optical rotation.
Opt=ModRedundant
1 12 S 10 0.1		 Relaxed scan: a line such as "1 12 S 10 0.1" (distance 1–12, ten steps of 0.1 Å) after the coordinates steps the coordinate while optimizing the rest, giving an energy profile. The Scan keyword is a rigid scan without optimization.
Stable Tests the stability of the wavefunction; used for radicals and transition metals.

Opt options

Keyword What it does and when to use it
Opt=Tight Tightens the convergence criteria; use it when low frequencies or small energy differences matter.
Opt=TS Searches for a transition state (first-order saddle point) instead of a minimum.
Opt=CalcFC Computes exact force constants (the Hessian) at the first cycle; often used for TS searches (ReadFC can read them instead).
Opt=CalcAll Recomputes the Hessian every cycle; the calculation becomes much more expensive.
Opt=ReadFC Reads the Hessian from %chk (or %oldchk).
Opt=MaxCycles=N Maximum number of optimization cycles; increase when the job stops at the default.
Opt=MaxStep=N Maximum step size (the initial trust radius) in units of 0.01 Bohr or 0.01 rad (default 30); reduce it when the structure overshoots and oscillates.
Opt=ModRedundant Freezes bonds and angles; a card such as "1 12 F" follows the coordinates.
Opt=Cartesian Optimizes in Cartesian rather than internal coordinates; useful when internal-coordinate generation fails.
Opt=QST2 / QST3 Finds a TS from reactant and product (and a TS guess). Atom ordering must match.
Opt=NoEigenTest Suspends the check on the number of negative Hessian eigenvalues during a TS search. Use it when an extra negative eigenvalue stops the search; because the search may then converge to an unintended structure, always confirm with the Freq after convergence that there is exactly one imaginary frequency (TS errors).
Opt=Restart Restarts an optimization from the results stored in %chk.

SCF, accuracy and convergence

Keyword What it does and when to use it
SCF=XQC Adds quadratically convergent steps when the usual SCF method fails; the first remedy for a convergence failure.
SCF=Tight SCF convergence setting; the default in Gaussian 16 (often written explicitly in published inputs).
SCF=MaxCycle=N Maximum number of SCF iterations.
Integral=UltraFine Uses a finer integration grid; matters for Minnesota functionals and low frequencies. Default in Gaussian 16.
Integral=NoBasisTransform Disables automatic basis transformation; used for J calculations with explicit s functions via Gen.
Guess=Read Uses the wavefunction in %chk (or %oldchk) as the initial guess; good for continuing from a similar structure.
Guess=Mix Mixes the HOMO and LUMO to break α–β symmetry in the initial guess; for open-shell singlets with unrestricted methods (e.g. UB3LYP).
Geom=AllCheck Reads the title, charge, multiplicity and geometry from the checkpoint; the title, charge/multiplicity line and coordinates are not written.
Geom=Check Reads only the geometry from the checkpoint; the title and the charge/multiplicity line are still written (no coordinate block).
Restart Restarts a failed job from a saved read-write file (%rwf), e.g. frequencies or NMR. Use Opt=Restart to continue an optimization and IRC=Restart to continue an IRC.

Method, basis set and solvent

Keyword What it does and when to use it
B3LYP / M062X / PBE1PBE / wB97XD / CAM-B3LYP / mPW1PW91 Functional names. In Gaussian, PBE0 is written PBE1PBE and PBE is written PBEPBE. Choose according to the purpose (geometry, NMR, excited states).
6-31G(d) / 6-311+G(2d,p) / def2-TZVP / aug-cc-pVDZ Basis sets. "+" adds diffuse functions (important for anions, excited states, optical rotation); (d) and (2d,p) indicate polarization functions.
Gen / GenECP Specifies basis sets per element; cards of the form "element 0 / basis / ****" follow the coordinates. GenECP adds effective core potentials.
EmpiricalDispersion=GD3BJ Empirical dispersion correction; add to functionals such as B3LYP. The Minnesota family has no GD3BJ parameters; use GD3 if you add one.
SCRF=(SMD,Solvent=Methanol) Approximates solvent as a continuum. Models include SMD, PCM (= IEFPCM, the default) and CPCM; Solvent= names the solvent.
SCRF=(...,Read) Supplies detailed solvent settings in an extra input section after the coordinates.
Temperature=298.15 Pressure=1.0 Temperature (K) and pressure (atm) for the thermochemistry; match the experimental conditions.

Property options

Keyword What it does and when to use it
NMR=GIAO Computes shieldings with the GIAO method (the default).
NMR=SpinSpin Computes spin–spin couplings with all four terms (FC, SD, PSO, DSO).
NMR=(SpinSpin,Mixed) Two-step J calculation: the Fermi-contact term with an automatically augmented basis, the other three terms with the given basis.
NMR=FCOnly Computes only the Fermi-contact term; combined with a scaling factor for ¹H–¹H couplings.
NMR=ReadAtoms Restricts which atoms are included in the J calculation; a line such as atoms=H follows the coordinates.
TD=(NStates=N) Number of excited states to compute; set enough to cover the wavelength range you want to compare.
TD=(Singlets) / TD=(Triplets) Spin multiplicity of the excited states; singlets for ordinary ECD and UV.
CPHF=RdFreq Computes optical rotation or polarizability at a given wavelength; a line such as 589nm follows the coordinates.
Pop=NBO / Pop=Full Prints population analysis: charges and orbitals.
IOp(...) Direct control of internal options; appears when reproducing literature protocols (e.g. basis augmentation for J, IOp(3/10=1100000)).

IRC options

Keyword What it does and when to use it
IRC=Forward / Reverse Direction to follow. Which side is the reactant must be judged from the structures.
IRC=CalcFC / RCFC Compute the initial Hessian (CalcFC) or read it from the Freq %chk (or %oldchk) (RCFC).
IRC=MaxPoints=N Maximum number of path points; increase if the endpoint is still changing.
IRC=StepSize=N Step size per point (in 0.01 Bohr); smaller steps make the path more stable.
IRC=LQA / HPC Path-following algorithm. HPC is the default; try LQA when the corrector fails to converge.
IRC=Restart Continues a stopped IRC from %chk.

Output level and other keywords

Keyword What it does and when to use it
#n / # / #p / #t Output verbosity: #n (or just #) is normal, #p adds per-step information, #t is terse.
NoSymm Disables the use of symmetry; use it to keep the input orientation.
Symmetry=Loose Loosens the symmetry-detection tolerance.
MaxDisk=NGB Disk space available for scratch files; used to choose algorithms, so not every job stays within it.
FormCheck / Punch Writes results in additional formats.
Notes
  • This page is written for Gaussian 16. Defaults, available options and output formats may differ in Gaussian 09 and other versions; check the manual for the version you use.
