TS search errors

Wrong number of negative eigenvalues

Wrong number of Negative eigenvalues: Desired= 1 Actual= 2

Cause: The Hessian during the TS search has a second negative curvature besides the reaction direction. This describes the search in progress; it is separate from the number of imaginary frequencies in the Freq after convergence.

What to do
  1. Check the bond distances of the TS guess, the orientation of the reacting atoms and atom clashes. A poor guess is the most common cause.
  2. If the guess is reasonable, you can continue the search with NoEigenTest (input example). After convergence, always confirm with Freq that there is exactly one imaginary frequency.
  3. If it still does not converge or the extra negative curvature remains, run a mode-check Freq at the same geometry, identify the extra mode and displace ± along it.

TS step limit

Number of steps exceeded,  NStep= 100

Cause: The TS search did not converge within the cycle limit.

What to do
  1. Look at the trend of forces, displacements and the reacting bond distances in a viewer such as GaussView. In a TS search the energy can rise, so judge by these trends rather than by energy alone.
  2. If the reaction geometry is intact and converging, continue from the last computed geometry with Opt=(TS,CalcFC,MaxCycles=100).
  3. If it oscillates strongly, add MaxStep=2–5. If the reaction geometry has fallen apart, rebuild the guess.

Example rerun inputs

Continuing with NoEigenTest

From the last computed geometry, continue the search with the check on the number of negative eigenvalues suspended. Because it may converge to an unintended structure, confirm with the Freq after convergence that there is exactly one imaginary frequency and that its motion is the intended reaction.

%chk=ts_noeigen.chk
#p B3LYP/6-31G(d) SCRF=(SMD,Solvent=Methanol)
 Opt=(TS,CalcFC,NoEigenTest,MaxCycles=100)

Mode-check Freq (identifying the extra mode)

The structure need not be converged. Run Freq alone at the stopped geometry to obtain complete vibrational modes, then distinguish the reaction mode from the extra mode in a viewer such as GaussView.

%chk=ts_modes.chk
#p B3LYP/6-31G(d) SCRF=(SMD,Solvent=Methanol)
 Freq

Create two structures displaced ±0.05 Å along the extra mode and start a new TS search from each with Opt=(TS,CalcFC). See TS re-search for the procedure.

Below the route line, continue with a blank line, title, blank line, charge/multiplicity, coordinates and a final blank line (input anatomy). Keyword meanings are in the keyword reference. Match the functional, basis set and solvent of the original job.

Comparing the retries

For the original TS search and the + and − retries, tabulate the mode used, the displacement, the reacting bond distances and whether each converged, and decide which structure to take to the final Freq and IRC.

Notes
  • A Freq at an unconverged geometry is for finding directions only; do not use it as TS proof, for thermochemistry or as an IRC start. Run a final Freq after convergence.
