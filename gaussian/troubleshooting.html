出力末尾の文字列から原因を特定し、条件を直して再計算します。

エラーの探し方

出力ファイル（.log/.out）の末尾を見ます。Error termination の数行上に原因の文字列があります。終了行がなければ、まだ実行中か、時間・メモリ・ディスクの制限で強制終了された可能性があります。

入力の書式エラー（計算が始まる前に止まる）

出力が短く、l1.exe（ルート行の誤り）、l101.exe、l202.exe、l301.exe で Error termination している場合は、ほとんどが入力ファイルの問題です。次を順に確認します。

  1. 空行の位置：ルート行の後、タイトルの後、座標の後に1行ずつ。
  2. ルート行のキーワードの綴り（Opt Freq、B3LYP、6-31G(d)）。
  3. 電荷と多重度の行が1行だけあること。
  4. 座標が「元素記号 x y z」の4列であること。全角文字（全角スペースを含む）が混ざっていないこと。
  5. ModRedundant や基底関数の追加入力がある場合は、その後の空行。

入力ファイルの中身に正しい例があります。

座標の後の空行がない

End of file in ZSymb.

原因：座標（分子の指定）が読めません。座標の後の空行がないか、座標を .chk から読むつもりで Geom=Check を付け忘れています。Opt=QST2・QST3 で、分子の指定（タイトル行・電荷と多重度・座標）が2つ・3つそろっていない場合にも出ます。

対処：座標の後に空行を入れるか、ルート行に Geom=Check を加えます。QST2・QST3 では分子の指定の数を確認します。

入力行の書式エラー

QPErr --- A syntax error was detected in the input line.

原因：入力の1行が読めません。エラーの下に読めなかった行が出て、その下の ' が読めなくなった位置を示します。ルート行のほか、計算の途中で読む入力（例：NMR=ReadAtoms の原子の指定）でも起き、その場合は計算が何時間も進んだ後で止まることがあります。

対処：表示された行を、Gaussian のマニュアルにあるそのキーワードの入力の書式に合わせて直します。

電荷・多重度が電子数と合わない

The combination of multiplicity 1 and 9 electrons is impossible.

原因：電荷から求めた電子数と多重度の組み合わせがありえません。電子数が偶数なら多重度は奇数（1, 3, …）、奇数なら偶数（2, 4, …）です。

対処：電荷・多重度を直します。ラジカルの多重度を1にしていないか、イオンの電荷を変え忘れていないか、構造の水素が多すぎたり少なすぎたりしないかを確認します。

基底関数にない元素がある

Atomic number out of range for 6-31G basis set.

原因：指定した基底関数が定義されていない元素が構造に含まれています（例：6-31G(d) と I や Pt）。

対処：その元素を含む基底関数を選ぶか、Gen・GenECP で元素ごとに基底関数（重い元素には有効内殻ポテンシャル）を指定します。

原子が近すぎる

Small interatomic distances encountered:  6  1  7  2 ...
Problem with the distance matrix.

原因：2つ以上の原子が近すぎます（重なっていることもあります）。直前の行に、近すぎる原子の番号が組で出ます。ビューアーで構造を貼り付けたときに、構造が二重になっていることがあります。

対処：表示された番号の原子の座標を直すか、余分な原子を削除します。

メモリ・ディスク・チェックポイントのエラー

メモリを確保できない

galloc:  could not allocate memory.

原因：%mem で指定したメモリを確保できません。

対処：%mem を計算機の空きメモリより小さくします。ジョブ管理システムで実行する場合は、Gaussian は %mem より多く使うため、申請するメモリを %mem より多めにします。

ディスクの空きがない

Erroneous write. Write -1 instead of 3648000.

原因：一時ファイル（スクラッチ）を書くディスクの空きがないか、容量の制限（quota）を超えています。

対処：不要なファイル（途中で止まった計算の一時ファイルなど）を消すか、空きの多いディスクをスクラッチにして（GAUSS_SCRDIR）再実行します。

チェックポイント・一時ファイルが読めない

Operation on file out of range.
...
Error termination in NtrErr:
NtrErr Called from FileIO.

原因：Geom=AllCheck・Guess=Read・Opt=ReadFC などで .chk から読もうとした情報がありません。%chk のファイル名の誤りや、前の計算が途中で止まって .chk に書かれなかったことが原因です。.chk から何も読まない計算（Opt Freq など）の途中で出ることもあり、その場合は計算自身の一時ファイル（スクラッチ）が読めず、出力からは理由が分かりません。Operation on file out of range. の代わりに FileIO operation on non-existent file. と出ることもあります。

対処：%chk のファイル名と場所を確認します。前の計算が途中で止まっていた場合は、その .chk を使わずに座標から計算し直します。.chk から読まない計算の場合は、スクラッチのディスクの空きと、計算中に一時ファイルが消されていないかを確認して再実行します。
