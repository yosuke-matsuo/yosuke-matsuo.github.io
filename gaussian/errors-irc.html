IRCエラー

IRCのエラー

correctorが収束しない

Maximum number of corrector steps exceded

原因：経路を補正する反復（corrector）が上限内に収束しません。

対処
  1. SCFの失敗やメモリ・ディスク不足が先に起きていないかを確認します。
  2. 既定のアルゴリズム（指定なし、または IRC=HPC）でこのエラーが出た場合は、IRC=LQA に変えて同じTSから計算し直します。TSのFreqの .chk を %oldchk で読み、方向・MaxPoints・StepSize は元の計算と同じにします（下の入力例）。
  3. StepSize を小さくする（例：10 → 5）のも有効です。

IRCの上限到達

Maximum number of steps reached.

原因：MaxPoints まで進んで正常に止まった状態です。末端がまだ極小構造に着いていないことがあります。

対処
  1. 末端の構造を見ます。まだ大きく変化中なら、MaxPoints を増やして続けます。止まったIRCの .chk から IRC=(Restart,MaxPoints=N) で延長する方法と、TSのFreqの .chk から MaxPoints を増やして計算し直す方法（下の入力例と同じ形で、IRC=(RCFC,…) と %oldchk を使う）があります。
  2. 反応物・生成物らしい構造に達していれば、末端構造を Opt Freq で緩和して極小を確認します。

末端Optの回数上限

Number of steps exceeded,  NStep= 100

原因：IRC末端からの構造最適化が回数上限で止まりました。

対処：通常のOptと同じです（Optの回数上限）。

LQAで再追跡する入力例

%oldchk=ts_freq.chk
%chk=ts_irc_fwd_lqa.chk
#p B3LYP/6-31G(d) SCRF=(SMD,Solvent=Methanol)
 IRC=(RCFC,Forward,LQA,MaxPoints=80,StepSize=5) Geom=AllCheck Guess=Read

Reverse が失敗した場合は Forward を Reverse に、%chk を ts_irc_rev_lqa.chk に変えます。Geom=AllCheck はタイトル・構造・電荷・多重度を .chk から読むので、タイトル行から座標欄までは書きません。
