Gaussian入門

Gaussianキーワード一覧

書き方の決まりLink 0（% で始まる行）計算の種類Opt のオプションSCF・精度・収束計算方法・基底関数・溶媒物性計算のオプションIRC のオプション出力の詳しさ・その他

書き方の決まり

  • Link 0 の行は % で始め、ルート行より前に書きます。ルート行は # で始め、複数行に折り返せます（行の間に空行を入れずに続けて書きます）。
  • 大文字・小文字は区別されません。Opt と opt と OPT は同じです。
  • オプションが1つなら Opt=Tight、2つ以上なら Opt=(TS,CalcFC) のように括弧でくくります。
  • 汎関数と基底関数は B3LYP/6-31G(d) のようにスラッシュでつなぎます。Gen を使うときは座標の後に基底関数カードを書きます。

入力全体の構造ははじめてのGaussian計算を見てください。すべてのキーワードとオプションはGaussian公式のキーワード一覧にあります。

Link 0（% で始まる行）

キーワード 意味と使いどころ
%chk
%chk=catechin_opt.chk		 この計算の結果を保存するチェックポイントファイル名。あとで構造や波動関数を読み直すのに使います。計算ごとに別の名前にします。
%oldchk
%oldchk=ts_freq.chk		 別の計算のチェックポイントを読み込む指定。IRCでTSのヘシアンを再利用するときなどに使います。
%nprocshared
%nprocshared=8		 使用するコア数。実行する計算機の割り当てに合わせます。
%mem
%mem=16GB		 使用するメモリ量。大きすぎると実行環境の制限で落ちます。
%rwf 一時作業ファイルの場所。ディスクの速い領域を指定すると速くなることがあります。

計算の種類

キーワード 意味と使いどころ
SP 指定した構造でエネルギーだけを計算します（既定）。大きな基底関数でエネルギーを精密化するときに使います。
Opt 構造最適化。力がほぼゼロになる構造を探します。
Freq 振動数解析。最適化した構造が極小かTSかを虚振動の数で調べ、熱力学量も得られます。
Opt Freq 最適化の後に、同じ条件で振動数解析を続けて行います。
IRC TSから反応物側・生成物側へ経路をたどります。
NMR 核磁気遮蔽定数を計算します。既定はGIAO法。スピン結合定数は NMR=SpinSpin などを指定したときに計算します。
TD
TD=(Singlets,NStates=50)		 時間依存DFT。励起状態を計算し、UV・ECDに使います。
Polar
Polar=OptRot CPHF=RdFreq		 分極率。Polar=OptRot で旋光度を計算します。
Opt=ModRedundant
1 12 S 10 0.1		 緩和走査。座標の後に「1 12 S 10 0.1」（原子1–12の距離を 0.1 Å ずつ10回）のように書き、各点でほかの座標を最適化してエネルギー曲線を描きます。Scan キーワードは各点を最適化しない剛体走査です。
Stable 得られた波動関数が安定かどうかを調べます。ラジカルや遷移金属で使います。

Opt のオプション

キーワード 意味と使いどころ
Opt=Tight 収束条件を厳しくします。低い振動数や小さなエネルギー差を扱うときに使います。
Opt=TS 極小ではなく遷移状態（一次の鞍点）を探します。
Opt=CalcFC 最初のサイクルで力の定数（ヘシアン）を正確に計算します。TS探索ではほぼ必須です。
Opt=CalcAll 毎サイクルでヘシアンを計算します。確実ですが非常に重くなります。
Opt=ReadFC %chk（または %oldchk）のヘシアンを読み込んで使います。
Opt=MaxCycles=N 最適化の回数上限（サイクル数）。既定を超えて止まる場合に増やします。
Opt=MaxStep=N 1ステップの大きさの上限（初期の信頼半径。0.01 Bohr または 0.01 rad 単位、既定は30）。構造が行き過ぎて振動するときに小さくします。
Opt=ModRedundant 結合距離・角度を固定したり走査したりします。座標の後にカード（例：1 12 F）を書きます。
Opt=Cartesian 内部座標ではなくデカルト座標で最適化します。内部座標の生成に失敗するときに使います。
Opt=QST2 / QST3 反応物と生成物（とTS候補）からTSを探します。原子の順序を一致させます。
Opt=NoEigenTest TS探索中の、ヘシアンの負の固有値の数の検査を止めます。余分な負の固有値が出て探索が止まるときに使いますが、検査を止めたまま進めると目的と違う構造に収束することがあるので、収束後の Freq で虚振動が1つかを必ず確認します（TSエラー）。
Opt=Restart %chk の途中結果から最適化を再開します。

SCF・精度・収束

キーワード 意味と使いどころ
SCF=XQC 通常の方法でSCFが収束しないとき、二次収束法を追加で行います。Convergence failure の第一の対処です。
SCF=Tight SCFの収束条件の指定。Gaussian 16 では既定です（文献の入力には明示されていることがあります）。
SCF=MaxCycle=N SCFの反復回数の上限。
Integral=UltraFine 数値積分の格子を細かくします。M06系の汎関数や低振動数の精度に効きます。Gaussian 16の既定です。
Integral=NoBasisTransform 基底関数の自動変換を止めます。Gen で s 関数を明示するJ計算などで使います。
Guess=Read %chk（または %oldchk）の波動関数を初期推測に使います。似た構造の続きを計算するときに使います。
Guess=Mix HOMOとLUMOを混ぜて、α・βの対称性を崩した初期推測を作ります。非制限法（UB3LYPなど）で開殻一重項を求めるときに使います。
Geom=AllCheck タイトル・電荷・多重度・構造をチェックポイントから読みます。タイトル行から座標欄までは書きません。
Geom=Check 構造だけをチェックポイントから読みます。タイトル行と電荷・多重度の行は書きます（座標欄は不要）。
Restart 中断した計算を、保存しておいた read-write ファイル（%rwf）から再開します（振動数・NMRなど）。最適化の続きは Opt=Restart、IRCの続きは IRC=Restart を使います。

計算方法・基底関数・溶媒

キーワード 意味と使いどころ
B3LYP / M062X / PBE1PBE / wB97XD / CAM-B3LYP / mPW1PW91 汎関数の名前。GaussianではPBE0を PBE1PBE、PBEを PBEPBE と書きます。目的（構造・NMR・励起状態）に応じて選びます。
6-31G(d) / 6-311+G(2d,p) / def2-TZVP / aug-cc-pVDZ 基底関数。+ は拡散関数（アニオン・励起状態・旋光度で重要）、(d)・(2d,p) は分極関数の数を表します。
Gen / GenECP 元素ごとに基底関数を指定します。座標の後に「元素 0 / 基底名 / ****」の形でカードを書きます。GenECPは有効内殻ポテンシャル付き。
EmpiricalDispersion=GD3BJ 分散力（弱い引力）の経験的補正。B3LYPなどに加えます。M06系には GD3BJ のパラメータがなく、加える場合は GD3 を使います。
SCRF=(SMD,Solvent=Methanol) 溶媒効果を連続体で近似します。SMD・PCM（= IEFPCM、既定）・CPCM などがあり、Solvent= で溶媒名を指定します。
SCRF=(...,Read) 溶媒の細かい設定を追加入力で与えます。座標の後にカードを書きます。
Temperature=298.15 Pressure=1.0 熱力学量を計算する温度（K）と圧力（atm）。実験条件に合わせます。

物性計算のオプション

キーワード 意味と使いどころ
NMR=GIAO GIAO法で遮蔽定数を計算します（既定）。
NMR=SpinSpin スピン結合定数を4成分（FC・SD・PSO・DSO）すべて計算します。
NMR=(SpinSpin,Mixed) J計算の2段階法。FC項だけ自動で拡張した基底関数で計算し、残り3項は指定した基底関数で計算します。
NMR=FCOnly Fermi接触項だけを計算します。¹H–¹HのJで補正係数と組み合わせて使います。
NMR=ReadAtoms Jを計算する原子を限定します。座標の後に atoms=H のような行を書きます。
TD=(NStates=N) 計算する励起状態の数。比べたい波長域を覆うだけ必要です。
TD=(Singlets) / TD=(Triplets) 計算する励起状態のスピン多重度。ECD・UVでは通常一重項。
CPHF=RdFreq 旋光度や分極率を指定した波長で計算します。座標の後に 589nm のような行を書きます。
Pop=NBO / Pop=Full 電荷分布や軌道の解析を出力します。
IOp(...) 内部オプションの直接指定。文献の手順を再現するときに出てきます（例：J計算の基底拡張 IOp(3/10=1100000)）。

IRC のオプション

キーワード 意味と使いどころ
IRC=Forward / Reverse たどる向き。どちらが反応物側かは構造を見て判断します。
IRC=CalcFC / RCFC 出発点のヘシアンを計算する（CalcFC）か、Freqの %chk（または %oldchk）から読む（RCFC）かを指定します。
IRC=MaxPoints=N たどる点の数の上限。末端がまだ変化中なら増やします。
IRC=StepSize=N 1点あたりの刻み幅（0.01 Bohr単位）。小さくすると経路が安定します。
IRC=LQA / HPC 経路をたどるアルゴリズム。HPCが既定で、corrector が収束しないときに LQA を試します。
IRC=Restart 途中で止まったIRCを %chk から続けます。

出力の詳しさ・その他

キーワード 意味と使いどころ
#n / # / #p / #t 出力の詳しさ。#n（または # だけ）が標準、#p は各ステップの情報を追加、#t は最小限。
NoSymm 対称性の利用を止めます。入力の向きを保ちたいときに使います。
Symmetry=Loose 対称性の判定を緩めます。
MaxDisk=NGB スクラッチに使えるディスク量。計算のアルゴリズムの選択に使われ、すべての計算でこの量以下に収まるとは限りません。
FormCheck / Punch 結果を別形式で書き出します。
注意
  • このページは Gaussian 16 を対象としています。Gaussian 09 やその他の版では、既定値・使えるオプション・出力の書式が異なる場合があります。使用する版のマニュアルで確認してください。
