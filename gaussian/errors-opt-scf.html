Opt・SCFエラー

構造最適化（Opt）

Optの回数上限

Number of steps exceeded,  NStep= 100

原因：上限の回数までに構造が収束しませんでした（上限は MaxCycles。指定しなければ分子の大きさで決まります）。出力は Error termination で終わりますが、入力の誤りではなく、収束する前に止まった状態です。

対処
  1. 出力末尾の構造（最後の Input orientation / Standard orientation）を新しい入力の座標にして、同じ条件で再実行します。
  2. エネルギーが単調に下がっていれば、これだけでたいてい収束します。
  3. 大きく上下している場合の対処は、下の「最適化が振動する」にあります。
  4. 収束後は必ず Freq を計算し、Freq の部分にも Stationary point found が出ていることと、虚振動がないことを確認します。

最適化が振動する（エネルギーが上下し続ける）

原因：1回の移動（ステップ）が大きすぎる、推定したヘシアンが実際と合っていない、回転しやすい結合（ねじってもエネルギーがあまり変わらない結合）がある、などの理由で、構造が行ったり来たりしています。エラー文字列はなく、最終的に Number of steps exceeded になります。

対処
  1. GaussViewなどのビューアーでエネルギーの推移と構造を見て、振幅が小さくなっているか、同じ幅で往復しているかを判断します。
  2. 小さくなっていれば、上と同じく最後の構造から続行します。
  3. 往復し続けるなら、最後の構造から Opt=(CalcFC,MaxStep=5) で再実行します。CalcFC で正確なヘシアンから始め、MaxStep で1回の移動を小さくします（5 は例。既定は30）。

原子が一直線に並んで止まる

Linear angle in Tors.
FormBX had a problem.
Error in internal coordinate system.

原因：最適化の途中で3つの原子がほぼ一直線に並び、Gaussian が最適化に使う内部座標（結合角・二面角）を作れなくなりました（l103 で止まります）。

対処：出力末尾の構造から同じ条件で再実行します。また止まるなら、Opt=Cartesian（直交座標で最適化）で再実行します。Opt=Cartesian は収束までの回数が増えることが多いです。

Opt後のFreqで収束していない

         Item               Value     Threshold  Converged?
 Maximum Force            0.000038     0.000450     YES
 RMS     Force            0.000014     0.000300     YES
 Maximum Displacement     0.005385     0.001800     NO
 RMS     Displacement     0.002819     0.001200     NO

原因：Freq は正確に計算したヘシアンで収束を判定し直すため、推定したヘシアンを使う Opt と結果が食い違うことがあります。Freq の出力に Stationary point found. がなければ、虚振動の数が正しくても停留点ではなく、振動数と熱力学量は正しくありません。GaussView などのビューアーで虚振動0を確かめるだけでは分からないので、出力ファイルの Freq の部分をテキストで検索して確かめます。

対処：同じ .chk を使い、Freq で計算したヘシアンを読み込んで最適化を続けます（下の入力例）。汎関数・基底関数は元の計算に合わせます。再計算後の Freq でも Stationary point found. を確認します。

%chk=myfile.chk
#p B3LYP/6-31G(d) Opt=ReadFC Freq Geom=AllCheck Guess=Read

.chk が残っていない場合は、最適化の最後の構造の座標から Opt=CalcFC Freq で計算します（最初に正確なヘシアンを計算します）。

#p B3LYP/6-31G(d) Opt=CalcFC Freq

計算し直しても Stationary point found が出ない場合は、エネルギー曲面が平らな領域にある可能性があります。Gaussian 16 の既定の数値積分の格子は UltraFine です。Fine で計算しているなら Int=UltraFine を試します（比べる計算はすべて同じグリッドにします）。参考：Gaussian公式：FAQ

SCFの収束失敗

SCFが収束しない

Convergence failure -- run terminated.

原因：1つの構造の電子状態を求める反復計算（SCF）が収束しません。Opt・TS・IRCのどの計算でも起こります。

対処
  1. まず、よくある原因である電荷・多重度の誤りと、原子の衝突や異常な結合距離がないかを確認します。
  2. 問題がなければ、ルート行に SCF=XQC を加えて再実行します（通常の方法で収束しないとき、二次収束法を追加で行います）。
  3. XQCでも失敗するなら、収束した近い構造の .chk から Guess=Read で初期推測を読みます。開殻一重項を非制限法で計算している場合は Guess=Mix も試します。

SCF再計算の入力例

%chk=opt_scf.chk
#p B3LYP/6-31G(d) SCRF=(SMD,Solvent=Methanol)
 SCF=(XQC,MaxCycle=512) Opt=(CalcFC,MaxCycles=100) Freq

入力の残りの書き方は入力ファイルの中身、キーワードの意味はキーワード一覧にあります。汎関数・基底関数・溶媒は元の計算に合わせます。
