# yosuke-matsuo.github.io

松尾 洋介の個人ページ（GitHub Pages）。GauSift のサイトと同じデザイン。GauSift公開後にソフトウェアのページ・リンクを追加予定。

## 公開手順（初回）
1. GitHub で新しいリポジトリを作る。名前は必ず `yosuke-matsuo.github.io`、Public。
2. このZIPを展開し、中身（index.html など）をリポジトリの画面に「Add file → Upload files」でドラッグして Commit。
3. Settings → Pages → Build and deployment を「Deploy from a branch」「main / (root)」にする。
4. 数分後に https://yosuke-matsuo.github.io/ で表示される。

GauSift は別のリポジトリ（yosuke-matsuo/gausift）で同じく Pages を有効にすると /gausift/ に出ます。
